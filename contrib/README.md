# Contrib

This directory contains community-contributed scripts and applications that complement GuideLLM but do not quite fit into the main project.

Each contrib project should live in its own directory and include:

- A short README explaining its purpose, setup, and usage.
- Its own dependency definitions, such as a `requirements.txt`, so it can run independently of the main GuideLLM environment.

Any instructions given in the README or other documentation should assume the contrib project's directory is the working directory.
